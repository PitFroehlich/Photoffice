# Architecture Decision Records (ADRs)

Significant technical decisions are recorded here so every agent and developer knows *why* things are the way they are.

**File name:** `NNNN-short-title.md` (consecutive numbers, never reuse a number).
To change a decision, write a new ADR and mark the old one as `Superseded by NNNN`.

Template:

```markdown
# NNNN: <Title>

- **Status:** Proposed | Accepted | Superseded by NNNN
- **Date:** YYYY-MM-DD

## Context
What problem or situation forces a decision.

## Decision
What we decided.

## Consequences
What becomes easier or harder because of it.
```
